# 知序 · 数据结构复习平台

在 Algorithm Visualizer 基座上实现的个人本地 C 语言复习工作台。当前提供 **11 章目录、84 个教材教学入口、62 道可本地编程的精选题**。每个入口的具体操作、输入范围和实现特点见页面说明及 [内容覆盖清单](docs/COVERAGE.md)。

## 获取代码

```powershell
git clone https://github.com/CyrusHuang-coder/Data_Structure_Lab.git
cd Data_Structure_Lab
```

仓库结构与提交范围见 [仓库说明](docs/REPOSITORY.md)。

## 启动

双击本目录中的 **启动平台.cmd**。环境检查与构建完成后会打开浏览器：

**http://127.0.0.1:4174**

关闭网页后服务继续在本机运行。双击 **停止平台.cmd** 可结束由启动器创建的服务。停止服务不会删除草稿与学习记录。

运行环境为 Node.js 24 和可用的 GCC/GDB；开发环境使用 GCC 8.1、GDB 8.1。启动器会使用已有工具，也可通过 `DS_GCC`、`DS_GDB` 指定编译器与调试器路径。首次缺少 npm 依赖时安装需要联网；已安装后的教材、代码执行、测试和存档可以离线使用。

## 建议先试

1. 教材知识库 → 单链表插入 → 运行代码 → 单步进入 → 展开存储结构。
2. 栈与队列 → 顺序栈入栈 → 把 ADT 存储实现切换为链式 → 重新运行。
3. 树 → 中序遍历 → 查看每层调用参数与访问序列。
4. 精选练习 → 反转链表 → 完成函数体 → 提交测试 → 点击失败用例载入输入后回放。
5. 自由实验区 → 编写完整 `main` → 在 stdin 面板填写输入。

## 已实现的主要功能

- 62 道精选练习均已接入本地 C 编程。支持手动导入 LeetCode 题面、多标签分类、接口模板或自定义适配，以及自动收录失败提交的错题本。详见 [题目导入与错题本说明](docs/PRACTICE_IMPORT_AND_REVIEW.md)。

- 统一的浅深色视觉、柔和环境光、局部玻璃导航和按钮反馈；移动端提供导航抽屉。设置页可关闭装饰动效，也会遵循系统减少动态效果的偏好。详见 [视觉优化验收](docs/UI_UX_POLISH_2026-11-18.md)。

- 默认增大界面与代码字号；设置页提供 16px/18px、浅色/深色/跟随系统、六种主题色及自定义颜色，并记住此浏览器的选择。
- 章节采用独立配色和结构形状的彩色 SVG 标识，浅色与深色模式都保留章节辨识度。
- 指针经过的边、连接变化、最短路径/生成树前驱边同步高亮；刚断开的连接在当前步骤以虚线显示，箭头和标签随边变色。
- 由 GCC 编译、GDB 采集的实际 C 执行记录；代码位置、变量、结构图、辅助表和调用栈使用同一停点。
- 进入、跳过、跳出、前进、回退、播放速度、步骤滑条及结构变化跳转。采集过程可以停止。
- 链表、树、图、数组、串和多种链式存储视图；动态分配、释放记录和结构检查。
- 运行源码快照：修改草稿后，旧记录继续使用旧源码回放。
- 演示、补全和独立实现入口；学习与自测模式，自测调试开关。
- ADT 源码、参数注释和补全；顺序/链式栈队列切换；被考查的链表操作不能直接调用辅助库答案。
- ADT 接口库按 6 个存储板块浏览，33 个基础接口用独立卡片展示；可搜索接口、复制调用示例，按需展开参数、结构定义和单个接口实现。
- 精选题筛选、原题链接、C 接口、本地测试、失败输入、提示与参考代码。
- 对比两份代码或两个输入；分别步进或推进至两侧下一次结构变化。
- 草稿、用例、stdin、笔记、通过版本、测试提交、运行记录、本地备份与恢复。
- 练习和对比工作台默认按参数填写输入：数列直接用逗号或空格分隔，树允许 null，图边逐行填写；额外参数单独填写。JSON 移到可选的高级输入，旧草稿和用例继续兼容。
- 代码、可视化、运行状态三栏可拖动分隔条调整宽度，支持方向键微调、双击或按钮重置，并在当前浏览器按算法记住比例。窄屏自动换行。
- 运行状态分为局部变量、指针指向、全局状态、辅助数组、调用栈、输出结果及诊断信息；可折叠并记住栏目状态。指针显示节点编号与地址，本步变化单独标记，顶部可快速跳转栏目。

## 当前实现口径

教材覆盖以每个主题的可运行教学入口为单位。页面会写明具体实现，例如 B+ 树入口展示批量构建与范围查找，败者树入口采用固定四路重建教学版。更完整的操作变体、题目原站规模性能、教材逐页对应见 [实施范围与后续项](docs/ACCEPTANCE.md)。

当前使用本机原生执行，尚无容器隔离。分配跟踪可报告部分非法释放；完整 Sanitizer 检查和初始化有效性仍需补充。界面会明确显示这些运行条件。DeepSeek 已预留接口，默认关闭，当前不会发送代码。

## 文件位置

| 路径 | 内容 |
|---|---|
| `upstream/algorithm-visualizer/` | 保留上游 Git 历史的实际工程 |
| `src/study/`（工程内） | 中文工作台与可视化适配 |
| `study-server/`（工程内） | 编译追踪、教材、题目、判题与本地 API |

| `user-data/runs/` | 完整运行记录 |
| `artifacts/` | 验收日志与截图 |
| `implement-stage/` | 实施假设、阶段记录与审查材料 |

用户数据不提交到上游仓库。备份页面导出 SQLite 中的记录；完整执行记录在学习档案中单独导出。
