# 当前实现范围与验收口径

当前是可运行的个人本地复习版本。11 章目录均有 C 教学入口，具体内容从代码生成到 `COVERAGE.md`。各入口默认正常输入与配置的边界输入由独立预期结果核对。

## 已落地

真实 C 编译与追踪、源码快照、回放与步进、结构检查、数组/串/链表/树/图/工作表、内存生命周期、ADT 与参数提示、两种复习模式、62 道本站编程题、原题跳转、自定义题目导入与分类、错题本、独立导出验证、双代码/输入比较、SQLite 存档、通过版本留存、stdin、备份恢复、启动与停止脚本。图形使用按钮缩放，并支持居中、适应画布和最大化。

## 具体实现范围

| 模块 | 当前口径 |
|---|---|
| C 执行 | 已有 Windows 原生 GCC/GDB；环境默认可信个人代码 |
| 播放 | 有界采集后回放，支持采集停止；播放暂停与调试器实时暂停分开 |
| 内存检查 | 分配/释放记录、非法释放标记、已登记链接检查；初始化有效性仍为 unknown |
| AVL/B 树 | 完成态不变量参与测试，避免只有有序输出也通过 |
| B+ 树 | 批量构建、叶链与范围查询；逐次插入/删除变体待扩展 |
| 广义表 | 表头表尾、复制与深度；输入为有界嵌套整数数组 |
| 外部排序/文件 | 有界整数记录与逻辑块访问教学模型，未测量物理磁盘耗时 |
| 败者树 | 固定四路，每轮重建比较树，非通用增量更新版 |
| 教材对应 | 全书主题映射已做；尚需对照实际第 1 版目录/PPT逐页校准 |
| LeetCode | 55 道已配置本站 C 接口；目录另有仅跳转条目；通过本站测试与原站通过分开 |
| 规模 | 数组/树最多 32 项、图最多 12 顶点等教学限额；原站完整规模性能需另测 |
| 输入编辑 | 默认参数表单，数列/文本直接填写，树允许 null、图边逐行填写；可选高级 JSON，另有元素节点及图边编辑；画布拖动用于运行布局 |
| 对比 | 两份自定义代码/输入，各自步进与两侧结构变化推进；更细的语义事件自动对齐待扩展 |
| 工作台布局 | 三栏可拖动调整宽度，含键盘微调、最小宽度、重置、隐藏右栏与窄屏换行；按算法保存在当前浏览器 |
| 运行状态 | 变量、指针、全局、数组、调用栈、输出、诊断分区展示；支持折叠记忆、栏目跳转及本步变化标记 |
| AI | DeepSeek 服务接口预留并默认关闭，远程调用与密钥管理待接入 |

## 后续优先项

1. 在容器环境接入更完整的内存诊断和隔离，保留 native 作为个人备选。
2. 按实际课程 PPT 补齐各 ADT 的操作变体，尤其 B+ 更新、其他线索方式及更高效的外排实现。
3. 将少量小规模教学题解替换/补充为原题要求的最优复杂度实现，并扩大测试输入。
4. 增加表达式级执行事件、精确操作计数、实时调试器暂停及更细的事件对齐。
5. 继续完善图库直接连边和完整 trace 的保留预算。

最终通过的命令、用例数和浏览器结果以 `artifacts` 的实际输出为准。第一轮独立审查记录为同族 provisional；第二轮因服务额度未完成，后续修复由执行者测试验证。
