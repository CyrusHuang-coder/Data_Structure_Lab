# 精选练习、题目导入与错题本

## 内置题目

62 道精选练习均已配置 C 接口、本地输入构造、测试用例和判定规则。首页和导航数量取自实际目录，导入题目后同步增加。教材入口保持 84 个。

本轮补齐：160 相交链表、155 最小栈、225 用队列实现栈、232 用栈实现队列、133 克隆图、200 岛屿数量、49 字母异位词分组。

- 相交链表：values 为 A，values2 为 B 的独立前缀，position 是共享尾部在 A 中的下标，从 0 开始；-1 表示不相交。测试按节点身份检查返回指针。
- 栈队列设计题：values 为初始元素，operations 为操作序列，例如 `push:3, pop, empty`。最小栈提供 `getMin`，栈提供 `top`，队列提供 `peek`。平台负责创建和释放对象，保留原题 C 接口。
- 克隆图：输入无向、无重边、无自环图，顶点编号从 0 开始，Node.val 为编号加 1。检查起点连通分量的邻接关系、原图完整性和复制对象身份。
- 岛屿数量：行优先输入 0/1 网格，最多 32 项、每边最多 8；平台转为 char** 与列长数组。
- 字母异位词分组：最多 24 个小写单词，每词最多 24 字符；允许组及组内顺序不同。空单词可输入 `["", "a"]`。平台检查元素完整性和分组等价关系。

## 导入一题

1. 在精选练习点击“导入题目”。粘贴 LeetCode 原题链接、题名、题面与约束。当前采用手动粘贴题面，不自动抓取原站内容。
2. 填写分类标签，可用逗号分隔多个标签；选择难度。
3. 选择数组、链表、二叉树或字符串接口模板。填写入口函数名；模板会生成函数签名、参数构造和调用适配。
4. 填写测试输入和预期结果。普通模板沿用参数输入界面，支持直接输入数列。整数或布尔结果填写 result（布尔值为 0/1）；数组及链表结果填写 output。未使用的字段留空；预期空数组填写 `[]`。
5. 点击“检查接口”或直接保存。平台编译检查函数签名与测试调用，保存成功后在“我的导入”中开始编程。

每题支持 1～20 个用例。输入相同的用例不能重复保存。导入题可编辑接口、标签与用例，可导出为本站题目 JSON 文件并重新载入。删除题目会从目录移除，已有代码草稿、提交和错题笔记仍保留；使用备份可恢复题目。

修改接口或测试用例后，旧代码草稿继续保留，通过状态会等待重新提交验证。仅修改题名、标签或题面时保留通过状态。

平台按配置的预期结果测试导入题。运行时可以尝试其他输入；若要在提交测试中加入新输入，应先在题目配置里填写它的预期结果。接口检查只确认适配可以编译，算法正确性由测试确认。

## 复杂接口配置

选择“自定义 C 接口与适配”，可填写附加类型定义、输入结构、参数构造、调用和返回值读取的 C 代码。平台全局变量如下：

| 输入结构 | 可用变量 |
| --- | --- |
| 数组 | `a`、`n`、`key` |
| 链表 | `lc_head`，节点类型 `struct ListNode` |
| 二叉树 | `root`，节点类型 `struct TreeNode` |
| 字符串 | `text`、`pattern` |
| 图 | `first`、`matrix`、`n`、`key` |

将整数结果赋给 `result`；将返回数列逐项写入 `ds_output[ds_output_len++]`。多参数和特殊返回类型可在适配代码里构造及转换。自定义适配的测试输入使用 JSON 定义字段；保存后的工作台继续按已有字段生成输入面板。

导入题采用现有结构可视化和调试器。数组、链表、树等模板复用对应视图；特殊用户类型会进入局部变量、存储和调试信息。若要增加新的专用图形，需要另写可视化适配。

## 错题本

- 未通过的提交自动加入错题本，记录失败次数、失败提交和时间。取消提交不计入失败。
- 可从题目列表或工作台手动加入。
- 点击“查看错题”填写错误原因、复习标签和思路笔记，并查看最近失败的代码、输入、预期结果和实际结果。
- 通过测试后保留复盘记录；勾选“已掌握”后从待复习列表隐藏。使用“显示已掌握”可重新查看；再次提交失败会重新进入待复习。
- 所有内容保存在本机 SQLite 中。设置页的备份与恢复同时包含导入题目和错题记录。

## 实现与验证

接口补齐：`study-server/problems-pending.mjs`。导入定义：`custom-problems.mjs`。编译检查：`validate-interface.mjs`。界面：`src/study/ProblemPage.jsx` 与 `problems.css`。运行、提交、导出继续复用原有 GCC/GDB 通路。

`tests/practice.test.mjs` 覆盖七个新增接口的默认和边界测试、全部导入模板编译、指针身份错误实现的拒绝、导入执行、错题记录及备份恢复。`artifacts/practice-browser.json` 记录界面端到端结果，包括数量、标签、配置编辑、真实失败提交、失败快照、持久化和移动端适配。
